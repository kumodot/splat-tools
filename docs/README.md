## Setting the social preview

It is **not** picked up from the repo automatically. Upload it by hand once:

**Settings > General > Social preview > Edit > Upload an image**, then pick
`docs/social-preview.png`.

GitHub wants 1280x640 and caps the file at 1 MB. Once set it sticks, and the
only reason to touch it again is a redesign.
